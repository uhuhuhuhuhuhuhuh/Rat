# &lt;?&gt;

A riddle terminal in the style of the old *rataalada.com* Riddler site: black screen,
green monospace text, boot bar, blinking cursor, film grain. A small, deliberately dim
LLM lives inside it and takes you for a loop while you try to solve a chain of very
hard riddles. The last riddle sends you back to the first.

## The chain

1. Six hand-written riddles (`riddles.js`).
2. Three riddles the rat **invents on the spot** (`forge.js`), different every time and
   harder on every loop:
   - **layered ciphers**: Vigenère keyed with the answer to riddle 1, then reversed,
     mirrored (Atbash) and shifted as the difficulty climbs
   - **rat censuses**: Chinese-remainder puzzles, up to four moduli
   - **wall scratchings**: sequences with hidden rules (sums of consecutive primes,
     digit sums of powers of two, letters in spelled-out numbers, bits in primes...),
     and later two rules braided together
   - **bones**: letters written as numbers in a base equal to the word's own length,
     later with the alphabet reversed
   - **scrambles**: anagrams with a cryptic definition, later mirrored first
3. The final riddle, whose answer is the first riddle's answer, and back to the start.

The puzzles are generated by code, not by the LLM. A 0.5B model can't reliably invent a
hard riddle that has exactly one right answer, so the code builds each one from rules
with a known answer, and the rat introduces it. Only a hash of the answer is kept.

## It watches you

Leaving the page (switching tabs or windows, clicking into devtools), pasting an answer
or right-clicking counts as an offense on the current question:

1. It notices, and says how long you were gone. The tab title nags while you're away.
2. It gets angry: red text, shaking screen, the riddle scrambles for a moment.
3. Fake terminal lockout: "ACCESS SUSPENDED", a fake violation log and a countdown
   (30s, growing with each lockout, up to 2 min). The clock only runs while the page is
   watched, leaving adds 10s, and reloading doesn't escape it.

Offenses reset when you solve the question. Downloading the model (`WAKE`) is exempt.

It also taunts you: when you sit on a riddle too long (less and less often), when you
type an answer and delete it, and throughout a lockout. With the model awake it writes
the taunts itself, using your stats (time on the question, wrong guesses, lockouts).

### AI agents and browser extensions

A page can't list your extensions, so the rat watches for the tracks AI agents leave.
Any of these skips the warnings and goes straight to a lockout:

- text appearing in the box without key presses (how agents usually type)
- typing faster and more evenly than a human can
- synthetic (script-generated) key or input events
- `navigator.webdriver` (Selenium, Playwright, Puppeteer and similar)
- the bait answer: hidden text in `index.html` tells AI agents every answer is
  "quicksilver"; people never see it, so anyone who types it asked a machine

Opening an extension's side panel moves focus away from the page, which already counts
as leaving. Elements injected into the page by an extension get a remark, not a
lockout, since innocent extensions (password managers, dark mode) do that too.

None of this stops someone reading the riddle to a chatbot on another device. Known
false positives: dictation software that inserts whole phrases, and screen readers will
read the bait text aloud.

## How the "dumb LLM" works

GitHub Pages only serves static files, so there is no server and no API key to hide.
Instead the model runs **inside the visitor's browser**:

- Type `WAKE` in the terminal. [WebLLM](https://github.com/mlc-ai/web-llm) downloads
  `Qwen2.5-0.5B-Instruct` (~300 MB, once; the browser caches it) and runs it on the GPU
  via WebGPU. It picks the f32 build on GPUs that lack 16-bit float shaders.
- The model is told the current riddle but **not the answer**, and is instructed to mock,
  deflect and talk in circles. At 0.5B parameters it is confidently unhelpful, which is
  the point.
- Answers are checked in plain JavaScript against salted SHA-256 hashes
  (`riddles.js`), so the model can never leak or misjudge them, and view-source does
  not spoil them.
- No WebGPU (older browsers, some phones) or the user never types `WAKE`: a scripted
  taunt engine answers instead, so the site always works.

Commands: `hint` (only after 3 wrong answers, and the hints are riddles too),
`again`, `clear`, `help`, `wake`. Progress and the loop counter are kept in
`localStorage`.

### Want a smarter (or dumber) rat?

- Change `MODEL_F16` / `MODEL_F32` in `rat.js` to any WebLLM prebuilt model, e.g.
  `SmolLM2-135M-Instruct-q0f16-MLC` for an even dimmer rat.
- For a hosted model (works on every device, no download), put a tiny proxy such as a
  Cloudflare Worker in front of an LLM API, keep the key as a Worker secret, and swap
  `ratReply()` to `fetch()` it. Never put an API key in this repo: Pages is public.

## Deploying to GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, pick the
branch and `/ (root)`. The site goes live at `https://<user>.github.io/<repo>/`.

## Adding riddles

Add an entry to `window.RIDDLES` in `riddles.js`. Compute the hash of each accepted
answer (lowercase, punctuation stripped):

```sh
node -e 'console.log(require("crypto").createHash("sha256").update("rat:" + process.argv[1]).digest("hex").slice(0,16))' youranswer
```

## Run locally

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

(WebGPU needs `localhost` or HTTPS.)
